# 写真・動画圧縮（syashin-syukusyou）

スマホの写真と動画を **その場で軽くする** ためのウェブツールです。
ブラウザだけで動き、**ファイルは端末の外に出ません**（サーバーへの送信は一切なし）。

- 📱 iPhone / Android / PC のブラウザでそのまま動く
- 🔒 アップロードなし。読み込み・圧縮・保存のすべてが端末内で完結
- 🖼 写真は何枚でもまとめて処理して、ZIP か共有シートで保存
- 🎬 動画も縮小・再エンコード（解像度とビットレートを下げて容量を削減）
- 🧭 撮影日時は残す／位置情報は消す、といった Exif の扱いを選べる
- ✈️ 一度開けばオフラインでも使える（ホーム画面に追加可能な PWA）
- 📦 依存パッケージ・ビルド不要。静的ファイルを置くだけ

## 使い方

1. 「写真・動画を選ぶ」から選ぶ（ドラッグ＆ドロップ・貼り付けも可）
2. プリセット（かるく／おすすめ／きれい）を選ぶ
3. 写真は自動で圧縮されます。動画は「変換」ボタンを押したときだけ処理します
4. 「保存」または「まとめて保存（ZIP）」で書き出す

元のファイルは書き換えません。常に別ファイルとして書き出すので、
容量を空けたい場合は保存後に元のファイルを削除してください。

### 動画について

動画は **再生しながら録り直す** 方式で変換します。そのため:

- 変換には **動画の長さと同じくらいの時間** がかかります（1 分の動画なら約 1 分）
- 変換中はページを開いたままにしてください
- 設定を変えても動画は自動で再変換しません（「もう一度変換」を押したときだけ）
- フレームレートは 30fps を上限にします（60fps の動画は 30fps になります）
- 保存形式は端末が対応するものを選びます（iPhone・最近の Android は MP4/H.264、それ以外は WebM）

### スマホで使う

公開した URL をスマホのブラウザで開き、ホーム画面に追加するとアプリのように使えます。

- **iPhone**: 共有ボタン →「ホーム画面に追加」。保存は共有シートの「画像を保存」から
- **Android**: メニュー →「アプリをインストール」。写真アプリの共有先としても選べます

## 公開する（GitHub Pages）

ビルドは不要です。このリポジトリをそのまま配信すれば動きます。

1. GitHub の **Settings → Pages** を開く
2. **Source** を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/syashin-syukusyou/` で開けます

> Service Worker と「共有先として使う」機能は HTTPS（または localhost）でのみ有効です。

## 設定について

| 項目 | 内容 |
| --- | --- |
| 長辺の最大サイズ | 写真の長い辺をこのピクセル数に収めます。**ファイルサイズへの影響が最も大きい** 設定です |
| 画質 | JPEG / WebP の品質。写真なら 75〜85 が目安。数字を下げるほど軽くなります |
| 保存形式 | 自動（写真は JPEG、透過があれば WebP か PNG）／ JPEG ／ WebP ／ PNG |
| 撮影情報（Exif） | 既定では全削除。「撮影日時・カメラ情報は残す」を選ぶと日付順の並びを保てます。位置情報は明示的に選んだときだけ残ります |
| 動画の音声 | そのまま残すか、削除してさらに軽くするか。動画のビットレートは長辺・画質の設定から自動で決まり、元の動画より高くはなりません |
| 元より大きくなる場合 | 圧縮しても縮まない画像は、元のファイルをそのまま使います |

目安として、スマホで撮った 4000×3000 程度の写真は「おすすめ」設定で **1/5〜1/15** ほどになります。
動画は元の撮影設定によりますが、4K や高ビットレートで撮ったものほど大きく減ります。

## 仕組み

- `createImageBitmap` で画像を読み、Canvas 上で **半分ずつ段階的に** 縮小してから再エンコードします（一度に縮小するより滑らかになり、巨大な写真でもメモリを抑えられます）
- Exif の向き（Orientation）の扱いはブラウザによって異なるため、**判定用の小さな画像を実際に読み込んで挙動を測り**、必要なときだけ自分で回転させます
- Canvas で再エンコードすると Exif は失われるので、必要なタグだけを選び直して APP1 セグメントを組み立て直します（回転は画素に焼き込むので Orientation は 1 に、画素数は出力サイズに書き換え、サムネイルと GPS は既定で削除）
- 動画は `<video>` を再生しながら Canvas に描き、`canvas.captureStream()` と `MediaRecorder` で録り直します。音声は Web Audio 経由で録画用ストリームに繋ぎます。ffmpeg.wasm のような大きな依存を持ち込まず、端末のハードウェアエンコーダをそのまま使えるのが利点で、代わりに変換が実時間かかります
- ZIP は無圧縮（store）形式で組み立てます。JPEG は既に圧縮済みで deflate してもほぼ縮まないため、外部ライブラリなしで済ませています。CRC は Blob をストリームで読みながら計算するので、大きな動画を入れてもメモリを使い切りません

## 開発

依存パッケージはありません（Node.js 20 以上）。

```sh
npm start      # 動作確認用のサーバーを起動（同じ Wi-Fi のスマホからも開けます）
npm test       # Exif / ZIP / 表示まわりのユニットテスト
npm run icons  # icons/*.png を再生成（python3 が必要）
```

### ファイル構成

```
index.html              画面
styles.css              見た目
src/app.js              画面の組み立て（選択・設定・結果表示・保存）
src/compress.js         写真の縮小と再エンコード
src/video.js            動画の縮小と再エンコード
src/exif.js             Exif の読み取り・組み立て直し・差し込み
src/zip.js              無圧縮 ZIP の生成
src/format.js           サイズ表示やファイル名などの小物
sw.js                   オフライン対応と「共有先」の受け取り
manifest.webmanifest    PWA の定義
tools/serve.js          開発用の静的サーバー
tools/make-icons.py     アイコン生成
test/                   ユニットテスト
```
